# 慢慢说：普通话跟读练习

适配安卓手机的静态网页。示范音频提前准备，声音检测在本机进行，无需账号、数据库或 AI 服务。

## 当前版本

包含 10 条日常短句及微软晓晓普通话神经语音（zh-CN-XiaoxiaoNeural），语速 -10%，MP3 格式。用户比较四句样音后选择晓晓，全部十句已按相同设置准备。每句默认示范两遍，音频结束后检测跟读；检测到声音后连续安静默认 3 秒，自动进入下一遍或下一句。本组结束停止。家属可选择每句 1—3 遍，以及安静 2、3、5、8 秒后推进。

点击开始时同时发起播放与麦克风准备，音频不再等待麦克风授权结果；提前加载当前音频并给其他短句添加预取提示，同句重播保留缓冲。首次弱网加载仍可能等待。

支持开始／继续、暂停、再听一次和下一句。麦克风不可用或不愿授权时，可选择手动模式，说完后点击“我说完了”。“再听一次”是额外示范，不增加预设示范的完成次数。

声音仅在本机进行音量检测，不录音、不上传，不识别患者所说文字、不纠正发音或评分。安静检测并不等于准确判断患者说完；背景人声、电视、弱声或句中长停顿可能影响检测，需在实际手机和环境中验证。音频为演示内容，适用性应由语言治疗师确认。

已加入本机设置和进度保存：记录示范次数、安静时间、当前短句和本句进度。刷新或重新打开后，进行中的练习保持暂停，点击继续后才播放或检测；整组已结束则保持停止。进度按短句编号恢复，原短句被删除时回到第一句并暂停。家属设置中的“回到第一句，重新开始”清除进度，保留设置。

设置和进度只保存在同一设备、同一浏览器、同一网址的本机存储中。清除浏览器数据、换设备、换浏览器或换网址可能丢失；隐私模式可能仅临时保存。浏览器无法保存时会提示，但仍可练习。不会保存患者声音或跨设备同步。

已加入异常处理：清单格式、编号唯一性、文字及相对音频路径检查；清单加载失败可重新加载，音频失败可重试或下一句，不会假装播放成功或无声跳过。清单加载 15 秒无回应会提示超时；音频加载或播放 20 秒无进展会停止并提示重试。这些超时只用于资源故障，不限制患者跟读时间。

连续快速点击下一句或再听一次会合并为一次操作；暂停立即生效。麦克风检测异常会释放设备并提供手动确认。

已加入后台保护：切到后台、页面冻结或离开页面时暂停并释放麦克风；返回、解冻或历史页面恢复不会自动播放。浏览器中断声音或麦克风时也暂停；失效的授权结果不能重新启动练习。

已完成第一版本地开发和可执行的整体验证。实际桌面浏览器已检查 320、390 像素测试框中的布局及全部音频的元数据读取；这不是安卓手机或实际发声验收。GitHub Pages 尚未部署，没有手机访问网址。

## 电脑本地预览

在本目录打开终端，运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后在当前电脑浏览器打开 `http://127.0.0.1:8765/`。不能直接双击 HTML：清单加载需要 HTTP。此地址仅适用于当前电脑，不能作为手机测试网址。

手机麦克风功能需通过 HTTPS 网站并允许浏览器使用麦克风。手机自带浏览器是否兼容，需要实际测试。参考：[麦克风授权及安全页面要求](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。

## 项目结构

- `index.html`、`styles.css`：页面与手机布局。
- `app.js`：按钮、麦克风授权和页面状态。
- `group-practice.mjs`：整组练习流程。
- `speech-end.mjs`：本机声音及安静检测。
- `local-state.mjs`：本机设置保存、短句编号恢复和损坏记录处理。
- `content-loader.mjs`：清单校验、加载超时及家属错误提示。
- `page-lifecycle.mjs`：页面后台、冻结和返回时的保护。
- `content/phrases.json`：短句清单。
- `audio/`：与短句对应的普通话 MP3 示范文件。
- `tests/`：模拟流程和声音检测测试。
- 中文验证记录：每步结果和未验证事项。
- `家属使用与维护说明.md`：使用、上传音频、修改清单、部署检查和恢复旧内容的完整中文说明。
- `第8步-整体验证与交付.md`：最终本地检查及剩余事项。
- `generate-demo-audio.ps1`：早期 Windows 演示音频生成记录；当前正式音频已替换。
- `generate-xiaoxiao-audio.py`：使用 edge-tts 联网生成晓晓音频，输出到指定独立目录；手机播放不调用在线语音服务。
- `generate-kokoro-audio.py`：历史 Kokoro 音频生成脚本。
- `音频来源说明.md`、`audio-generation-record.json`：当前音频来源、生成参数和文件校验值。

## 修改内容

每条短句都需要唯一编号 `id`、显示文字 `text` 和音频相对路径 `audio`。清单顺序就是练习顺序。修改文字时要同步修改音频；只改文字不会产生新声音。完整操作及清单示例请见 [家属使用与维护说明](家属使用与维护说明.md)。仓库地址和手机网址在正式发布后补齐。
